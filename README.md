# pz-collection
Presets, load orders, and mod options for a vanilla+ Project Zomboid B42.22+ solo and multiplayer mod collection.

The **Zomboid** folder goes in your user folder; on Windows you can press the Windows key and type %USERPROFILE% then hit enter to open your user folder. Replace the existing files.
